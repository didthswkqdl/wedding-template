# 💌 참여형 모바일 청첩장 템플릿

**서버 비용 0원**으로 만드는 모바일 청첩장입니다. 하객은 웨딩 사진을 넘겨 보며 **사진마다 댓글**을 달고, **방명록**에 축하 메시지를 남길 수 있습니다. 모든 글은 **내 Google 스프레드시트**에 저장되고, 사진은 **내 Google Drive**에 저장됩니다.

👉 **[데모 보기](여기에_데모_링크)** — 미리보기 모드라서 작성한 글은 내 브라우저에만 임시 저장됩니다.

## 이런 걸 할 수 있어요
- **메인 인트로**: 대표 사진, 신랑·신부 이름, 날짜, 초대 문구
- **초대의 글**: 인사말, 혼주 성함(故 표시), 신랑·신부에게 전화·문자
- **예식 안내**: 달력과 D-day, 예식장 정보, 네이버 지도·카카오맵 연결, 주소 복사, 교통·주차 안내
- **웨딩 갤러리**: 사진 확대, 좌우 스와이프, **사진별 댓글**과 댓글 수 표시
- **방명록**: 최신순 목록과 '더 보기'
- **마음 전하실 곳**: 신랑측·신부측 계좌 접기/펼치기, 계좌번호 복사, 카카오페이 링크
- **마무리 인사**: 공유하기, 링크 복사, 처음으로
- **관리자 페이지**
  - 청첩장 내용 전체 수정(이름·날짜·문구·계좌 등)
  - 사진 업로드·순서 변경·삭제
  - 댓글·방명록 삭제
- **보안**
  - 관리자 비밀번호는 해시로만 저장하고, 서버가 매번 권한을 확인합니다.
  - 악성 스크립트(XSS)와 시트 수식 주입을 차단합니다.
  - 중복 등록과 도배를 막습니다.

## 구조
```
📁 이 저장소
├── README.md            ← 지금 보는 안내서
├── LICENSE
├── apps-script/         ← 구글 Apps Script 에 넣는 서버 코드
│   ├── Code.gs
│   ├── Setup.gs
│   └── appsscript.json  (선택)
└── docs/                ← 청첩장 웹사이트 (GitHub Pages 가 이 폴더를 보여줌)
    ├── index.html       ← 하객용 청첩장
    ├── admin.html       ← 관리자 페이지
    ├── config.js        ← ★ 서버 주소(API_URL) 입력
    ├── css/  js/  images/
```

| 구분 | 사용 기술 |
|---|---|
| 화면 | HTML·CSS·JavaScript → **GitHub Pages**(무료) |
| 서버 | **Google Apps Script 웹 앱** |
| 데이터 | **Google Sheets** (PHOTO_LIST · PHOTO_COMMENTS · GUESTBOOK · SETTINGS 시트 자동 생성) |
| 사진 | **Google Drive** (관리자 페이지에서 업로드) |

## 준비물
1. **개인 Gmail 계정**
   - 회사·학교(Google Workspace) 계정은 공개 배포나 링크 공유가 막혀 있는 경우가 많습니다.
2. **GitHub 계정** (https://github.com 무료 가입)
3. PC (설정은 PC에서, 확인은 스마트폰에서)

설치는 약 20~30분 걸립니다. 아래 순서대로만 따라 하세요.

## 1단계. 구글 시트(서버) 복사하기
<!-- 배포자: 아래 '시트 사본 만들기' 링크를 실제 /copy 링크로 바꿔 주세요 (PUBLISHING.md 참고) -->
1. 개인 Gmail로 로그인한 상태에서 **[📄 시트 사본 만들기](여기에_사본_링크)**를 열고 **사본 만들기**를 누릅니다.
   - 스프레드시트와 서버 코드가 함께 내 드라이브로 복사됩니다.
   - 위 링크가 동작하지 않으면 '직접 만들기'를 펼쳐 따라 하세요.
     <details><summary>직접 만들기</summary>

     1. 주소창에 `sheets.new` 입력 → 새 스프레드시트
     2. **확장 프로그램 → Apps Script**
     3. 기본 `Code.gs` 내용을 지우고 이 저장소의 `apps-script/Code.gs` 전체를 붙여넣기
     4. **파일 ＋ → 스크립트** → 이름 `Setup` → `apps-script/Setup.gs` 전체 붙여넣기 → 💾 저장
     5. ⚠ Apps Script 에는 **Code.gs 와 Setup.gs 두 파일만** 넣으세요. docs 폴더의 html·css·js·txt 를 넣으면 오류가 납니다.
     </details>
2. 복사된 스프레드시트를 **새로고침**하면 상단에 **💌 청첩장 관리** 메뉴가 생깁니다.
3. **💌 청첩장 관리 → ① 초기 설정**을 누르고 권한을 승인합니다.
   - 순서: **권한 검토** → 내 계정 선택 → "Google에서 확인하지 않은 앱" 화면에서 **고급** → **(프로젝트명)(으)로 이동** → **허용**
   - 내가 복사한 내 스크립트라서 Google 심사를 받지 않았다는 뜻일 뿐입니다.
   - 한 번 더 **① 초기 설정**을 누르면 시트 4개와 Drive 사진 폴더가 만들어집니다.
4. **💌 청첩장 관리 → ② 관리자 비밀번호 설정**에서 8자 이상(12자 이상 권장)으로 정합니다.
   - 비밀번호는 해시로만 저장되어 어디에도 그대로 남지 않습니다.
5. (선택) **💌 청첩장 관리 → 자가 진단 테스트 실행** → 모두 ✅ 인지 확인합니다.

## 2단계. 서버를 웹 앱으로 배포하기
1. 스프레드시트에서 **확장 프로그램 → Apps Script**로 들어갑니다.
2. 오른쪽 위 **배포 → 새 배포** → "유형 선택" 옆 **⚙ → 웹 앱**을 고릅니다.
3. 아래처럼 설정합니다.
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포** → (권한 승인) → **웹 앱 URL**(`…/exec`로 끝나는 주소)을 복사합니다.
5. 확인: 그 주소를 브라우저에서 열어 `{"ok":true, …}` 가 보이면 성공입니다.
   - 이 주소는 청첩장 화면이 아니라 **서버 주소**입니다.

## 3단계. 청첩장 화면(GitHub) 만들기
1. 이 저장소 오른쪽 위 초록색 **Use this template → Create a new repository**를 누릅니다.
   - 이름 예: `wedding`
   - **Public** 선택 → **Create repository**
2. 새로 생긴 **내 저장소**에서 `docs/config.js` 를 열고 **연필(✏️) 아이콘**을 누릅니다.
3. `API_URL: ''` 의 따옴표 안에 2단계에서 복사한 `/exec` 주소를 붙여넣습니다.
   ```js
   API_URL: 'https://script.google.com/macros/s/……/exec',
   ```
   **Commit changes**를 누릅니다.
4. `docs/index.html` 을 열고 연필을 눌러, 맨 위 **카카오톡 미리보기 6줄**을 내 정보로 바꾼 뒤 **Commit changes**를 누릅니다.
   - 바꿀 것: 이름, 날짜, 예식장, 그리고 `YOUR-GITHUB-ID` / `YOUR-REPO`
5. 저장소 **Settings → Pages**에서 Branch를 **`main`**, 폴더를 **`/docs`**로 고르고 **Save**를 누릅니다. (⚠ `/ (root)` 가 아니라 **`/docs`**)
6. 1~3분 뒤 같은 화면 위쪽에 주소가 표시됩니다.
   - **청첩장**: `https://내아이디.github.io/저장소이름/`
   - **관리자 페이지**: `https://내아이디.github.io/저장소이름/admin.html`

## 4단계. 내용과 사진 채우기
1. **관리자 페이지**에 로그인합니다(1단계에서 정한 비밀번호).
2. **청첩장 내용** 탭에서 아래 항목을 입력하고 **[저장]**을 누릅니다.
   - 이름, 혼주, 날짜·시간, 예식장, 문구, 교통 안내, 계좌번호
3. **사진 관리** 탭 → **사진 선택하기**로 웨딩 사진을 여러 장 올리고 ↑↓로 순서를 정합니다.
4. **청첩장 내용 → 대표 사진**에서 첫 화면·마무리 사진을 **갤러리 사진에서 고르기**로 지정합니다.
5. 카카오톡 미리보기 사진을 올립니다.
   - 저장소 `docs/images` 폴더 → **Add file → Upload files**
   - 가로 1200×630 사진을 **`og.jpg`** 라는 이름으로 올립니다.
6. 청첩장 주소를 카카오톡 **나에게 보내기**로 보내 열어 봅니다. 완성입니다! 🎉

## 테스트 체크리스트
| 확인 | 기대 결과 |
|---|---|
| 청첩장 맨 위에 갈색 "미리보기 모드" 띠가 **없다** | 서버와 연결됨 (있으면 `API_URL` 확인) |
| 방명록 작성 | 스프레드시트 `GUESTBOOK` 시트에 행이 추가됨 |
| 사진 확대 → 댓글 작성 | `PHOTO_COMMENTS` 시트에 행이 추가되고, 사진 아래 댓글 수가 +1 |
| 새로고침 | 쓴 글이 그대로 남아 있음 |
| 등록 버튼 여러 번 빠르게 누르기 | 시트에 1건만 저장됨 |
| 관리자 페이지에서 삭제 | 시트에서 행이 지워짐 |
| 휴대폰 '뒤로가기' | 사진 창이 닫힘 (청첩장에서 나가지 않음) |

## 자주 생기는 문제
| 증상 | 해결 |
|---|---|
| Apps Script 실행 시 `SyntaxError` | Apps Script 에 Code·Setup 외의 파일(html·css·js·txt)이 들어감 → 삭제 |
| `/exec` 접속 시 `ReferenceError: window…` | docs 폴더의 js 파일이 Apps Script 에 들어감 → 삭제 후 **새 버전으로 재배포** |
| "서버 응답을 확인할 수 없어요" | 배포 설정이 **나 / 모든 사용자**인지 확인, `/exec` 주소인지 확인, 회사 계정이면 개인 Gmail 사용 |
| Apps Script 코드를 고쳤는데 그대로임 | **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** (주소는 그대로 유지) |
| 관리자 [청첩장 내용] 저장 시 "지원하지 않는 요청" | 예전 Code.gs → 최신 `apps-script/Code.gs` 로 교체 후 새 버전 배포 |
| 갤러리 사진이 "사진 없음" | Drive 사진 공유 설정 확인. 계속 안 되면 사진을 `docs/images/` 에 올리고 관리자 [링크로 추가]에 `images/파일명.jpg` 입력 |
| 사진 업로드 시 "공유 설정에 실패" | 회사·학교 계정 제한 → 개인 Gmail 로 다시 설치 |
| GitHub 주소가 404 | Pages 폴더가 **`/docs`** 인지 확인, 1~3분 대기 |
| 카카오톡 미리보기가 예전 것 | [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 캐시 초기화 |
| 시트를 직접 고쳤는데 바로 안 바뀜 | 메뉴 **시트를 직접 고친 뒤 즉시 반영하기** (자동 반영은 최대 60초) |

## 알아 두세요 (기술적 제약)
- **사진 주소**: Google Drive 사진 주소는 공식 이미지 서버가 아닙니다. 드물게 사진이 안 보일 수 있으며, 그럴 때는 다른 주소로 자동 재시도합니다. 가장 안정적인 방법은 사진을 `docs/images` 폴더에 넣는 것입니다.
- **응답 속도·동시 접속**: Apps Script 응답은 0.5~3초 걸립니다. 동시 실행에는 한도(계정당 약 30건)가 있어, 순간 접속이 몰리면 잠시 지연될 수 있습니다(자동 재시도 포함).
- **카카오톡 미리보기**: 링크 미리보기의 제목·사진은 `docs/index.html` 에서만 바꿀 수 있습니다. 관리자 페이지로는 바뀌지 않습니다.
- **공개 파일**: `config.js` 는 누구나 볼 수 있는 파일입니다. 비밀번호 같은 비밀 정보는 절대 넣지 마세요. 관리자 비밀번호는 스프레드시트 메뉴로만 설정합니다.
- **업데이트**: 이 템플릿이 업데이트돼도 이미 복사해 간 청첩장에는 자동으로 반영되지 않습니다. 새 파일로 교체하면 됩니다(Code.gs 는 교체 후 새 버전 배포).
